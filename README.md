# GUESS THE NUMBER
A simple and interactive game where you must guess the secret number that the computer has chosen.

## 📝 Description
Guess The Number is a classic web game developed with HTML, CSS and vanilla JavaScript. The goal is to guess a random number generated by the computer within a specific range. The game provides hints after each attempt to help you find the correct number.

## 🎮 Features
- Clean and easy-to-use interface
- Automatically generated random number
- Hint system (higher/lower)
- Attempt counter
- Option to restart the game
- Responsive design

## 🛠️ Technologies used
- **HTML5** - Document structure
- **CSS3** - Styles and responsive design
- **JavaScript** - Game logic and interactivity

## 📋 Requirements
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No additional installations required

## 🚀 Installation and usage
1. **Clone or download the repository**
   ```bash
   git clone [repository-URL]
   ```
   Or download as ZIP and extract the files.

2. **Navigate to the project directory**
   ```bash
   cd guess-the-number
   ```

3. **Open the game**
   - Double-click the `index.html` file, or
   - Open the `index.html` file with your preferred browser, or
   - If you have a local server installed:
     ```bash
     # With Python 3
     python -m http.server 3000
     
     # With Node.js (if you have http-server installed)
     npx http-server -p 3000
     
     # With PHP
     php -S localhost:3000
     ```
   Then visit `http://localhost:3000` in your browser.

## 🎯 How to play
1. Open the `index.html` file in your browser
2. The game will automatically generate a secret number
3. Enter your guess in the input field
4. Click "Guess" or press Enter
5. The game will give you a hint:
   - "Too high" if your number is greater than the secret
   - "Too low" if your number is less than the secret
   - "Correct!" if you guessed the number
6. Keep guessing until you find the correct number
7. Use the "New game" button to play another round

## 🔧 Customization
You can easily modify:
- **Number range**: Edit the variables in `script.js`
- **Visual styles**: Modify `styles.css` or the styles in `index.html`
- **Game messages**: Change the texts in the JavaScript code
- **Difficulty**: Adjust the number range or add attempt limit
